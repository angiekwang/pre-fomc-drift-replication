# Lucca and Moench (2015) Replication

This project replicates the daily size-portfolio FOMC dummy regression table in Lucca and Moench’s "The Pre-FOMC Announcement Drift" found in Table B.3. I use daily Fama-French size portfolio returns and scheduled FOMC meeting dates from September 1994 to March 2011. For each portfolio, I regress daily excess returns on an FOMC announcement-day dummy and compare the estimated coefficients to Table B.3.
